# Avrora TV

Android TV приложение с каналами по языкам, радио и (скрытыми пока) веб-камерами.

## Что внутри

- **Каналы** — 7 169 живых каналов из [iptv-org](https://github.com/iptv-org/iptv), только потоки, ответившие на проверке доступности. Русский список отсортирован по узнаваемости (Первый, НТВ, ТНТ, СТС…), названия переведены на русский с оригиналом в скобках.
- **Радио** — 8 213 станций из [radio-browser.info](https://www.radio-browser.info/), сортировка по стране/названию, российские и англоязычные первыми.
- **Избранное** — отдельные списки для каналов, радио и камер (камеры пока отключены флагом `Features.cams`).
- **Плеер** — Media3/ExoPlayer: автозапуск, выбор лучшего качества, переключение на следующий поток при ошибке, сторожевой таймер 20 с.
- **Оформление** — рассвет: фото, тёплая палитра, анимация свечения, `#FFC46B`.

## Сборка

```bash
# JDK 17+, Android SDK 35
./gradlew :app:assembleRelease   # или gradle :app:assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk` (подписан debug-ключом для сайдлоада).

## Данные

Каталоги собираются скриптами из `tools/`:

| Скрипт | Что делает |
|---|---|
| `build_catalog.py` | каналы: iptv-org playlists + `feeds.csv` (язык потока, а не канала), рейтинг РФ-каналов, перевод названий |
| `probe_all.py` | проверка всех потоков на доступность → `_data/alive.json` |
| `build_radio.py` | радио из radio-browser.info |
| `build_cams.py` | веб-камеры из датасета Famelack (сейчас выключены в UI) |

Скрипты скачивают данные в `_data/` и кладут готовые JSON в `app/src/main/assets/`.

## Лицензии данных

- iptv-org — CC0
- Famelack — MIT
- radio-browser.info — общедоступный каталог

Приложение не хранит видео: только ссылки на публичные потоки.
